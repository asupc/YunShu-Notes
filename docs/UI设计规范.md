# 跨端笔记平台高保真 UI 与交互原型设计文档（V2.0）

覆盖 Web、PC 桌面端与 Android 移动端的完整设计系统、7 大核心界面原型、4 张高保真 PNG 视觉稿索引、组件状态矩阵与深色模式适配规范。设计核心：以极简低噪画布承载长文阅读，用无限层级目录树彻底取代笔记本切换栏，并为 Word/Excel 的「轻量预览 + PC 本机打开回传」提供无歧义的状态反馈。

## 3. 七大核心界面原型交互细则

### 原型 1：PC / Web 主工作区与无限层级目录树

* **布局比例**：左栏默认 `260px`（拖拽区间 `200px–420px`，`Ctrl+\` 一键折叠）；中栏自适应（正文默认居中 `780px`，支持宽屏切换）；右栏大纲/属性默认收起，展开占 `240px`。

* **目录树拖拽反馈**：拖至节点上/下边缘 `20%` 区域出现 `2px` 蓝色横线（同级排序）；拖至节点中部 `60%` 区域整行高亮浅蓝边框（挂载为子节点）；悬停在折叠节点上 `500ms` 自动展开，方便深层拖放。

* **深层级可视辅助**：嵌套超过 5 级时自动绘制纵向 `1px` 虚线参考轴，左侧栏底部支持轻微横向滚动以防深层标题截断。

### 原型 2：Office 文件预览视图与 PC 本机同步栏

* **顶部工具栏（高度 48px）**：左起依次为文件类型图标 + 文件名 + 版本下拉胶囊（`v4`）+ 同步状态徽章；右起为「用本机 Office 打开（主按钮）」「版本历史」「下载/更多」。

* **状态提示条（高度 32px，按需显示）**：当 PC 端唤起本机 Word/Excel 后，工具栏上方滑出淡琥珀色提示条「检测到文件已在外部打开，按 `Ctrl+S` 保存后将自动同步回云端」，关闭外部程序或回传完成后自动淡出。

### 原型 3：版本历史抽屉（右侧滑出 `300px`）

* 按时间倒序展示版本列表（`v4 当前版本`、`v3`、`v2`...），每条记录显示：版本号、修改时间、来源设备（如 `ThinkPad-PC`）、文件大小与「预览 / 恢复」操作。

* 点击历史版本可在中间画布切换为只读对比预览，顶部出现「正在查看历史版本 v2 — 恢复为最新版」操作栏。

### 原型 4：版本冲突对比弹窗（居中模态框 `560px`）

* 当 PC 本地编辑回传触发服务端 `409 Conflict` 时弹出，左右双卡并排对比：

  * **左卡（本机最新修改）**：显示本地修改时间、文件大小、`SHA-256` 前 8 位、来源设备。

  * **右卡（云端最新版本）**：显示云端修改时间、设备来源与版本号。

* **底部三选一操作**：「保留两者（推荐，本机另存为冲突副本）」「以本机覆盖云端」「放弃本机改动并拉取云端」。默认推荐「保留两者」，确保零数据丢失。

### 原型 5：全局搜索与命令面板（`Ctrl+K` 居中浮层 `620px`）

* **输入区**：支持关键词即时检索 + 快捷过滤芯片（`全部` / `笔记` / `Markdown` / `Word` / `Excel` / `仅当前目录`）。

* **结果行结构**：每行展示 2 层信息——首行显示类型图标 + 高亮命中标题 + 节点类型标签；次行显示完整面包屑路径（如 `研发架构 / 同步协议`）与命中正文/Excel 单元格的上下文摘要片段。

* **键盘导航**：`↑/↓` 移动选中、`Enter` 跳转、`Ctrl+Enter` 在新标签页/分屏打开、`Esc` 关闭。

### 原型 6：Android 移动端三核心页面流

* **目录页（首页）**：顶部圆角搜索框，主体为触控友好的无限层级树（单行高 `48dp`，右侧展开箭头热区 `44×44dp` 防止误触进入正文），右下角悬浮 `+` 按钮点击展开速记菜单（新建笔记 / 上传文档 / 拍照扫描），底部三标签（目录 / 最近 / 搜索）。

* **笔记阅读与编辑页**：顶部精简返回键与更多菜单，点击正文直接进入编辑态，键盘上方吸附单行横向可滚动格式条（H1/H2、粗体、待办、列表、插图、缩进）。

* **Office 预览页**：主体为支持双指捏合缩放的 PDF 预览画布，底部固定操作条提供「用其他应用打开（调用手机 WPS / Microsoft 365）」与「下载/分享」。

### 原型 7：OneNote 一键迁移 3 步向导

* **步骤 1（选源）**：左右双选卡片——「本地 `.onepkg` 归档包（推荐，极速无限制，支持拖入）」与「连接微软账号（Graph API，后台限流拉取）」。

* **步骤 2（映射预览）**：左侧展示解析出的 OneNote 笔记本/分区/页面树，支持勾选局部导入；右侧选择目标挂载目录（默认 `根目录 / OneNote归档`）与选项开关（`内嵌 Word/Excel 自动转为子节点`）。

* **步骤 3（后台续传）**：实时进度条、已迁移/总页数、当前速率、暂停/继续按钮；若部分页面失败，底部列出失败清单与「一键重试失败项」按钮；支持点击「最小化到左下角」在后台静默运行。
