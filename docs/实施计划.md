# 跨端笔记平台工程级详细实施方案（V2.0）

本方案面向服务端、Web、PC（Windows / macOS / Linux）与 Android 四端，聚焦「单一无限层级节点树（无笔记本隔阂）+ 富文本与 Markdown 离线协同 + OneNote 一次性全量迁移 + Word/Excel 上传预览与 PC 本机 Office 编辑自动回传」。所有模块均给出可直接落地的工程目录、数据库 DDL、API 契约、状态机逻辑、部署配置与 W1–W16 周级拆解。

## 2. 数据库完整 DDL 与树形操作算法

### 2.1 核心数据表结构（PostgreSQL）

```
CREATE EXTENSION IF NOT EXISTS ltree;
CREATE EXTENSION IF NOT EXISTS pgcrypto;

-- 1. 用户与多端设备表
CREATE TABLE users (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email         TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at    TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE sync_devices (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  device_name   TEXT NOT NULL,               -- 例: ThinkPad-X1 / Pixel-9
  platform      TEXT NOT NULL,               -- 'web' | 'windows' | 'macos' | 'linux' | 'android'
  last_seen_at  TIMESTAMPTZ DEFAULT now()
);

-- 2. 统一无限层级节点表（笔记 / 目录 / Markdown / Word / Excel / PDF）
CREATE TABLE nodes (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  parent_id       UUID REFERENCES nodes(id) ON DELETE CASCADE,
  path            LTREE NOT NULL,            -- 例: root.n_9f1a.n_2b3c（UUID 去连字符前缀）
  rank            TEXT NOT NULL,             -- LexoRank / Fractional Indexing 排序键
  title           TEXT NOT NULL,
  node_type       TEXT NOT NULL CHECK (node_type IN ('folder','note','markdown','docx','xlsx','pdf')),
  icon            TEXT,                      -- 可选自定义图标标识
  yjs_state       BYTEA,                     -- note/markdown 节点的 Yjs 二进制合并快照
  current_file_id UUID,                      -- 文件节点指向最新 node_files.id
  current_version INT DEFAULT 1,             -- 文件乐观锁版本号
  plain_text      TEXT DEFAULT '',           -- 抽取的纯文本（含 Office 文档内容）
  is_pinned       BOOLEAN DEFAULT FALSE,
  is_deleted      BOOLEAN DEFAULT FALSE,
  deleted_at      TIMESTAMPTZ,
  created_at      TIMESTAMPTZ DEFAULT now(),
  updated_at      TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_nodes_user_path_gist ON nodes USING GIST (path);
CREATE INDEX idx_nodes_parent_rank ON nodes (user_id, parent_id, rank) WHERE is_deleted = FALSE;
CREATE INDEX idx_nodes_updated ON nodes (user_id, updated_at DESC);

-- 3. 文件资产与版本历史表（支持 PC 保存自动回传与版本回滚）
CREATE TABLE node_files (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  node_id         UUID NOT NULL REFERENCES nodes(id) ON DELETE CASCADE,
  version         INT NOT NULL,
  file_name       TEXT NOT NULL,
  mime_type       TEXT NOT NULL,
  file_size       BIGINT NOT NULL,
  sha256          CHAR(64) NOT NULL,
  storage_key     TEXT NOT NULL,             -- S3 路径: users/{uid}/files/{sha256}/{filename}
  preview_pdf_key TEXT,                      -- 异步生成的 PDF 预览路径
  preview_status  TEXT NOT NULL DEFAULT 'pending', -- 'pending' | 'ready' | 'failed'
  source_device   TEXT,                      -- 来源设备名
  created_at      TIMESTAMPTZ DEFAULT now(),
  UNIQUE (node_id, version)
);
CREATE INDEX idx_node_files_sha256 ON node_files (sha256);

-- 4. OneNote 一次性迁移任务与断点续传表
CREATE TABLE import_jobs (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  source_type     TEXT NOT NULL CHECK (source_type IN ('graph_api','onepkg_local')),
  target_node_id  UUID REFERENCES nodes(id) ON DELETE SET NULL,
  status          TEXT NOT NULL CHECK (status IN ('queued','running','paused','done','failed')),
  total_pages     INT DEFAULT 0,
  imported_pages  INT DEFAULT 0,
  failed_pages    INT DEFAULT 0,
  cursor_state    JSONB DEFAULT '{}'::jsonb, -- 已完成页面集合与 Graph 分页 nextLink
  error_log       JSONB DEFAULT '[]'::jsonb, -- [{pageTitle, reason, retryable}]
  created_at      TIMESTAMPTZ DEFAULT now(),
  updated_at      TIMESTAMPTZ DEFAULT now()
);

```

### 2.2 无限层级子树移动的原子 SQL（`ltree`）

当用户拖拽一个包含数百个子节点的目录到新父节点下时，仅需一条事务 SQL 即可完成整棵子树的路径重写，防止循环引用：

```
-- 将节点 :nodeId 及其全部后代移动到新父节点 :newParentId 下
-- 1. 前置校验：禁止将节点移动到自身或其后代节点下
SELECT 1 FROM nodes WHERE id = :newParentId AND path <@ (SELECT path FROM nodes WHERE id = :nodeId);

-- 2. 原子更新整棵子树 path 与当前节点 parent_id / rank
UPDATE nodes
SET path = :newParentPath || subpath(path, nlevel(:oldPath) - 1),
    parent_id = CASE WHEN id = :nodeId THEN :newParentId ELSE parent_id END,
    rank = CASE WHEN id = :nodeId THEN :newRank ELSE rank END,
    updated_at = now()
WHERE user_id = :userId AND path <@ :oldPath;

```

## 3. 服务端 REST API 与 WebSocket 协议契约

### 3.1 核心 REST 接口清单

| 接口分组 | 方法与路径 | 核心请求参数 / 响应结构 | 关键逻辑说明 | 
| ----- | ----- | ----- | ----- | 
| 目录树拉取 | `GET /api/v1/nodes/tree` | Query: `since`（增量时间戳）  Res: `{ nodes: NodeMeta[], serverTime }` | 启动时仅返回树元数据（不含 `yjs_state` 与 `plain_text`），支持增量差量同步。 | 
| 创建节点 | `POST /api/v1/nodes` | Body: `{ parentId, title, nodeType, prevRank, nextRank }` | 服务端自动生成 `ltree` 路径与中间 `rank`，返回新建节点完整元数据。 | 
| 移动与排序 | `PATCH /api/v1/nodes/:id/move` | Body: `{ newParentId, prevRank, nextRank }` | 校验无环后执行 `ltree` 子树移动；若 `rank` 碰撞则自动重排同级兄弟节点。 | 
| 申请文件上传 | `POST /api/v1/files/presign` | Body: `{ nodeId, fileName, fileSize, sha256, mimeType }` | 先查 `sha256` 是否已存在（支持秒传），否则返回 S3 PUT 预签名 URL（有效期 10 分钟）。 | 
| 提交文件版本 | `POST /api/v1/files/commit` | Body: `{ nodeId, baseVersion, storageKey, sha256, fileName, deviceName }` | **核心乐观锁**：若 `nodes.current_version === baseVersion`，版本 +1 并投递预览/索引队列；若不等，返回 `409 Conflict` 并按客户端选择自动创建「冲突副本」子节点。 | 
| 获取预览与下载 | `GET /api/v1/nodes/:id/file-urls` | Query: `version`（可选）  Res: `{ downloadUrl, previewPdfUrl, previewStatus, sha256, version }` | 返回时效 15 分钟的私有桶签名链接，保障私有笔记文件不外泄。 | 
| 全局全文检索 | `GET /api/v1/search` | Query: `q`, `types`（逗号分隔）, `rootId`（限定子树范围） | 联合检索 `title` 与 `plain_text`，返回高亮摘要片段与节点面包屑路径。 | 
| 迁移任务控制 | `POST /api/v1/migrations/graph` / `POST .../pause` / `POST .../retry` | Body: `{ accessToken, targetNodeId, notebookIds }` | 创建、暂停、恢复或仅重试失败页面的 OneNote 迁移任务。 | 

### 3.2 Hocuspocus（Yjs）实时同步握手协议

* **连接地址**：`wss://your-domain.com/ws/collab?token=<JWT>`，文档房间名固定为 `node:<node_uuid>`。

* **鉴权钩子（`onAuthenticate`）**：校验 JWT 合法性并确认当前 `user_id` 拥有该 `node_uuid` 的读写权限。

* **加载与落盘钩子（`onLoadDocument` / `onStoreDocument`）**：首次打开房间从 `nodes.yjs_state` 恢复 `Y.Doc`；编辑停止 2 秒防抖后将合并后的 `Uint8Array` 写回 `nodes.yjs_state`，并同步抽取纯文本更新 `nodes.plain_text` 以实时刷新全文搜索索引。

## 4. PC 端 Tauri 2.0 本地 Office 唤起与自动回传状态机

这是替代 OneNote 桌面端最核心的体验模块。在 Rust 侧实现一个独立的状态机 `OfficeSyncManager`，专门解决 Microsoft Word / Excel 保存机制带来的工程边界问题。

### 4.1 工作目录与本地状态机

* **缓存路径约定**：`{app_cache_dir}/office_workspace/{node_id}/{file_name}`，避免不同目录下同名文件（如多个 `预算.xlsx`）互相覆盖。

* **唤起流程**：前端调用 Tauri Command `open_office_node(node_id)` → Rust 查本地 SQLite 记录的 `local_sha256` 与服务端 `remote_sha256` → 不一致则流式下载至工作目录并写入记录 → 注册该目录的 `notify::RecommendedWatcher` → 调用 [tauri-plugin-opener](https://www.google.com/search?q=https%3A%2F%2Fv2.tauri.app%2Fzh-cn%2Fplugin%2Fopener%2F) 的 `open_path(&local_path)` 启动本机 Word / Excel / WPS → 向前端推送事件 `office:status { nodeId, state: "editing_local" }`。

### 4.2 处理 Word / Excel 保存的 4 个关键坑点

1. **忽略锁文件与临时文件**：Word/Excel 打开时会生成 `~$预算.xlsx`，保存时会先写 `8A3F2B10.tmp` 再与原文件互换。监听器必须过滤以 `~$`、`~WRL` 开头或 `.tmp` 结尾的事件，但**保留目标文件名的 `Modify` 与 `Rename`（原子替换）事件**。

2. **监听父目录而非单文件**：由于 Office 采用原子替换（删除旧 inode、重命名新 inode），直接监听单文件句柄会在第一次 `Ctrl+S` 后失效！必须监听 `{node_id}/` 目录并匹配目标文件名。

3. **1200ms 防抖 + 文件可读锁探测**：收到目标文件变更后延迟 1200ms，尝试以只读共享模式打开文件并计算 `SHA-256`；若被 Excel 短暂独占锁定（Windows `ERROR_SHARING_VIOLATION`），等待 500ms 重试最多 5 次。

4. **乐观锁冲突保护**：计算出的新 `SHA-256` 与上次同步值不同时，向前端发出 `uploading` 状态并执行 `presign → PUT S3 → commit(baseVersion)`。若服务端返回 `409 Conflict`，Rust 自动调用创建冲突副本接口（命名为 `原文件名 (冲突副本 YYYY-MM-DD HH-mm).xlsx`）并向前端弹出明确提示，绝不丢数据。

## 5. Web / Android 轻量预览与安全架构

* **异步 PDF 预览 Worker（主方案）**：`preview-worker` 消费 BullMQ 队列，使用隔离用户配置目录执行无头转换： `HOME=/tmp libreoffice --headless -env:UserInstallation=file:///tmp/lo_profile_<jobId> --convert-to pdf --outdir /tmp/out <input_file>`，设置 45 秒超时防止损坏文档卡死进程；转换成功后上传至 S3 `preview_pdf_key` 并将 `preview_status` 置为 `ready`。

* **零依赖前端兜底预览**：当 `preview_status !== 'ready'` 或用户关闭服务端转换时，Web/Android 自动降级为前端解析：`.docx` 使用 [docx-preview](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FVolodymyrBaydalka%2Fdocxjs)，`.xlsx` 使用 [SheetJS](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fsheetjs%2Fsheetjs.github.io) 读取多 Sheet 数据并用虚拟滚动表格渲染。

* **Android 端系统唤起**：通过 Tauri 2.0 Android 文件插件将缓存文件写入应用 `FileProvider` 共享目录，再调用系统 `ACTION_VIEW` Intent 交由手机上的 WPS / Microsoft 365 打开。

* **安全与隐私**：全站强制 HTTPS（Caddy 自动续期证书）；密码采用 Argon2id 哈希；Access Token 有效期 15 分钟 + HttpOnly Refresh Token 轮换；MinIO/S3 设为私有桶，仅允许通过服务端鉴权后的短时签名 URL 访问。

## 6. OneNote 一次性全量迁移深度算法

### 6.1 通道 A：Microsoft Graph API（云端限流稳态拉取）

* **遍历顺序**：`GET /me/onenote/notebooks` → `GET /notebooks/{id}/sectionGroups`（递归）→ `GET /.../sections` → `GET /sections/{id}/pages?select=id,title,level,order,createdDateTime,lastModifiedDateTime` → `GET /pages/{id}/content?includeIDs=true`（[Graph OneNote API 文档](https://www.google.com/search?q=https%3A%2F%2Flearn.microsoft.com%2Fen-us%2Fgraph%2Fonenote-get-content)）。

* **限流控制（核心）**：微软委托权限限额为 **120 次/分钟、400 次/小时、5 并发**，且 `429` 响应常无 `Retry-After`（[限流实测说明](https://www.google.com/search?q=https%3A%2F%2Fnote-bridge.co%2Fen%2Fblog%2Fmicrosoft-graph-rate-limiting-onenote)）。Worker 内置固定 3 并发 + 双层令牌桶（每分钟最多 90 次、每小时最多 360 次留安全余量）；遇 `429` 或 `503` 执行指数退避（30s → 60s → 120s → 300s），每完成 1 页立即写入 `import_jobs.cursor_state` 实现随时断点续传。

### 6.2 通道 B：本地 `.onepkg` 离线高速解析

* 用户在 Windows OneNote 桌面端导出 `*.onepkg` 后，在 PC 端直接拖入迁移向导。

* Tauri Rust 侧调用 [onenote.rs](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Fmsiemens%2Fonenote.rs) 解包 `.onepkg`（本质为 CAB/ZIP 归档，内含 `.onetoc2` 目录索引与各分区 `.one` 文件），直接解析出章节树、页面内容、内嵌图片与附件字节流，批量调用服务端入库接口，数千页笔记可在 5–10 分钟内完成迁移。

### 6.3 HTML 清洗与 ProseMirror AST 转换规则

1. **绝对定位容器线性化**：OneNote 输出 HTML 中含 `data-absolute-enabled` 的多栏 `<div style="position:absolute;left:...;top:...">`（[输出 HTML 规范](https://www.google.com/search?q=https%3A%2F%2Flearn.microsoft.com%2Fen-us%2Fgraph%2Fonenote-input-output-html)），按 `(top 整数分桶, left)` 升序重排为线性块级流，避免导入后重叠。

2. **层级还原**：读取页面的 `level`（0 / 1 / 2）与 `order`，维护栈结构将 `level=1` 挂载至前一个 `level=0` 页面下，`level=2` 挂载至前一个 `level=1` 页面下，完美保留 OneNote 子页面嵌套。

3. **媒体与内嵌 Office 拆分**：提取所有 `<img>` 上传至 S3 并替换为站内资产链接；提取所有 `<object data-attachment="...">`，若扩展名为 `.docx/.xlsx/.pdf`，自动在当前笔记节点下创建对应的文件子节点，并在正文原位置插入「文件引用卡片」。

4. **转为 Yjs 初始快照**：将清洗后的 HTML 通过服务端无头 ProseMirror Schema 解析为 JSON AST，再编码为 `Y.Doc` 二进制写入 `nodes.yjs_state`，确保迁移后第一秒即可多端协同编辑。

## 7. Docker Compose 自建部署与自动备份

服务端整套依赖仅需 1 份 `docker-compose.yml` 即可在 2C2G+ 的 Linux 服务器或 NAS 上一键拉起：

```
services:
  postgres:
    image: postgres:16-alpine
    restart: unless-stopped
    environment:
      POSTGRES_DB: note_platform
      POSTGRES_USER: note_admin
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - ./data/pg:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    restart: unless-stopped

    environment:
      MINIO_ROOT_USER: ${MINIO_USER}

  server:
    build: ../apps/server
    restart: unless-stopped
    depends_on: [postgres, redis, minio]
    environment:
      DATABASE_URL: postgres://note_admin:${DB_PASSWORD}@postgres:5432/note_platform
      REDIS_URL: redis://redis:6379

      JWT_SECRET: ${JWT_SECRET}

  preview-worker:
    build: ../apps/preview-worker     # 基础镜像含 libreoffice-nogui + fonts-noto-cjk
    restart: unless-stopped
    depends_on: [postgres, redis, minio]
    mem_limit: 1024m                  # 限制峰值内存，防止超大表格转换撑爆宿主机

  caddy:
    image: caddy:2-alpine
    restart: unless-stopped
    ports: ["80:80", "443:443"]

      - ./Caddyfile:/etc/caddy/Caddyfile
      - ./data/caddy:/data
```
